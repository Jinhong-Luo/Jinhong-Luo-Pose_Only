# Project Layout

Use this repository in three zones:

- active reruns and active configs:
  - `configs/paper_v2/`
  - `docs/paper_v2/`
  - `scripts/paper_v2/`
  - `runs/paper_v2/`
- scene assets and reusable frontend outputs:
  - `runs/strecha/`
  - `runs/ETH3D/`
  - `runs/ETH3D_repaired/`
- archived history:
  - `archive/2026-04-05_project_cleanup/`

The `tools/` directory is now grouped by role:

- root-level active scripts only
- root utility modules
